# note Scrapbook

開いている [note](https://note.com/) の記事を、本文と画像ごとローカルに保存する Chrome 拡張です。
Chrome ウェブストアには公開しない、自分用のツールとして作っています。

保存したフォルダはそのまま持ち運べます。プレビューはローカルサーバーを立てず、`index.html` を Finder からダブルクリックして開く前提です。

## インストール

1. このリポジトリをクローンする
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」からリポジトリのルートを選ぶ

## 使い方

1. note の記事ページ（`https://note.com/<ユーザー名>/n/<記事 ID>`）を開く
2. ツールバーの拡張機能アイコンをクリックする
3. 「この記事を保存」を押す

保存が終わるとポップアップに保存先と画像の件数が出ます。

### 添付ファイルへのナビゲーション

記事に添付ファイル（zip など）があるときだけ、画面右下にスクロール追従の小さなナビが出ます。項目を押すと本文中のダウンロードボタンまでスクロールし、その場所を一瞬枠で示します。× で閉じられます（再読み込みでまた出ます）。

これは記事を読むときの補助で、保存される `index.html` には含まれません。

## 保存されるもの

ダウンロードフォルダの下に、記事タイトル名のフォルダが作られます。

```
<ダウンロード>/note-scrapbook/<記事タイトル>/
├── index.html   … 確認用。ダブルクリックで開く
├── article.md   … 本文の Markdown
├── images/
│   ├── 001.png
│   └── 002.jpg
└── files/       … 本文に添付ファイルがあるときだけ作られる
    └── sample.zip
```

- `index.html` と `article.md` はどちらも `images/` を相対パスで参照するので、フォルダごと移動しても表示が崩れません
- `index.html` は CSS を内蔵した単体で完結する HTML です。外部のスクリプトやフォントは読み込みません。背景は白で固定していて、OS のダークモードには追従しません
- 本文に zip などの添付ファイルリンクがあれば `files/` に保存し、`index.html` と `article.md` のリンク先をそこに差し替えます。会員向けのファイルでも、ログイン中であればリンクをクリックしたときと同じように取得されます
- 同じ記事を保存し直すと同じフォルダに上書きされます

### 保存のたびにダイアログが出るとき

Chrome の設定「**ダウンロード前に各ファイルの保存場所を確認する**」がオンになっています。`chrome://settings/downloads` を開いてオフにしてください。

この拡張は 1 記事につき「画像 N 枚 + `index.html` + `article.md`」を書き出すため、この設定がオンだと 1 回の保存で N+2 回ダイアログが出ます。拡張側からは保存先を指定して「尋ねずに保存する」よう指定していますが、この設定はそれより優先されるため、拡張側では抑止できません。

### なぜ HTML と Markdown の両方を出すのか

`file:///` で開いた HTML から `.md` を JavaScript で読み込むことは、ブラウザのセキュリティ制約でできません。
そのため「Markdown で残す」と「ダブルクリックで確認する」を両立させるには、確認用の HTML を別に持つ必要があります。詳しくは [docs/spec.md](docs/spec.md) を参照してください。

## 制限事項

- 有料記事の未購入部分など、ページに表示されていない本文は保存できません
- 添付ファイルは、リンク先の URL をそのまま取得できるものだけが対象です。ボタンを押すと JavaScript で URL を組み立てるような配布方法には対応していません
- 大きな添付ファイルは、保存完了を待たずに結果表示が出ることがあります（ダウンロード自体はブラウザ側で続きます）
- X（Twitter）や YouTube などの埋め込みは、リンクとして残ります
- `note.com` と `assets.st-note.com` 以外にある画像は取得できません。その画像は元の URL のまま残るので、オンラインであれば表示されます
- 記事一覧やマガジンのページには対応していません
